Sinkron antar perangkat

Menyiapkan sinkron online...

Masuk dengan akun Google yang sama di komputer kantor dan di HP, maka pengingatnya akan sama di keduanya. Data disimpan di server Google (Firebase), jadi jangan menulis hal yang sangat rahasia di pengingat.

Suara dan alarm

Suara belum aktif: sentuh layar atau klik di mana saja sekali.

Agar tetap bunyi walau browser ditutup

Halaman web hanya bisa berbunyi selama halamannya masih terbuka. Supaya HP tetap berbunyi walau browser ditutup, masukkan jadwalnya ke aplikasi kalender di HP: tekan tombol "Ke kalender HP" pada pengingat, atau unduh semuanya sekaligus lalu buka filenya di HP.

Cadangan data

Simpan semua pengingat ke sebuah file sebagai cadangan, atau untuk memindahkannya ke perangkat lain. Buka file cadangan itu di sini untuk memulihkannya. Data yang sudah ada tidak dihapus.

Data tersimpan di browser perangkat ini, jadi tidak otomatis muncul di perangkat lain.
